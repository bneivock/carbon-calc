# carbon-calc
A Java-based CLI calculator designed to estimate personal daily CO2 emissions based on user habits, built as a foundational project for Software Engineering prep.

## Features
- Captures user input using `Scanner` for their daily beef consumption, how many hours the car and the air conditioner are being used and phone charging habits.
- Performs mathematical equations based on the average of CO2 produced by cars, ACs, phone charges and beef consumption.
- Evaluates specific conditions using basic control flow (`if` statements).
- All values for the CO2 that is produced come from averages acording to google searches

## Concepts Learned & Applied
- Variables & Data Types (`int`, `double`, `String`, `boolean`)
- Type conversion via `Integer.valueOf()` and `Boolean.valueOf()`
- Input/Output handling (`Scanner` & `System.out.println`)
- Basic Arithmetic Operations
- Conditional logic
